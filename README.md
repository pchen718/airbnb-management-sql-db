# Airbnb Management Database Project

## Overview

This project was developed as part of a business analytics and database systems course. The goal was to design and implement a relational SQL database for an Airbnb-style property management system that tracks renters, bookings, units, cleaners, contractors, and property ownership information.

The database helps property managers organize operational data, monitor booking activity, track repeat renters, manage maintenance records, and support reporting needs.

---

## Project Features

* Relational database design using SQL
* Entity Relationship Diagram (ERD) development
* Normalized tables with primary and foreign key constraints
* Business-focused reporting queries
* Booking and renter tracking
* Cleaner assignment and workload analysis
* Contractor payment tracking
* Owned vs. managed property analysis
